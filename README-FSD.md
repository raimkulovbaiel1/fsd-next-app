# Feature-Sliced Design (FSD) в Next.js проекте

Этот проект использует архитектурную методологию **Feature-Sliced Design (FSD)** для организации кода.

## Структура слоев FSD

```
src/
├── app/                    # Конфигурация приложения, провайдеры, роутинг (Next.js App Router)
│   ├── layout.tsx
│   ├── page.tsx           # Главная страница использует виджеты
│   ├── globals.css
│   └── ...
├── processes/             # Бизнес-процессы (переходы между страницами)
├── pages/                 # Страницы приложения (дополнительные к app/)
├── widgets/               # Крупные UI блоки, составленные из фич
│   └── hero/              # Hero секция главной страницы
│       ├── hero.tsx
│       └── index.ts
│   └── features/          # Блок преимуществи
├── features/              # Бизнес-функционал (авторизация, корзина и т.д.)
├── entities/              # Бизнес-сущности
│   └── user/              # Сущность пользователя
│       ├── index.ts       # Экспорты
│       ├── types/         # Типы TypeScript
│       │   └── user.ts
│       ├── lib/           # Бизнес-логика, API
│       │   └── user-service.ts
│       └── ui/            # UI компоненты сущности
│           └── user-card.tsx
└── shared/                # Переиспользуемые компоненты и утилиты
    ├── assets/            # Статические ресурсы (иконки, изображения)
    │   ├── icons/
    │   └── img/
    ├── ui/                # Общие UI компоненты
    │   ├── button/
    │   ├── FilterInput.tsx
    │   └── index.ts
    └── lib/                # Утилиты
        └── utils.ts        # Функция cn для классов
```

## Где верстать главную страницу?

### 🎯 **Главная страница** (`src/app/page.tsx`)
- Использует виджеты из `src/widgets/`
- Импортирует готовые блоки: `<Hero />`, `<Features />`
- Не содержит прямой верстки - только композиция виджетов

### 🧱 **Виджеты** (`src/widgets/`)
- Крупные блоки главной страницы
- **Hero** - заголовок, призыв к действию
- **Features** - преимущества, услуги
- **About** - информация о компании
- **Contacts** - контактная информация

### 🔧 **Общие компоненты** (`src/shared/ui/`)
- Переиспользуемые элементы: Button, Input, Card
- Используются во всех виджетах и фичах

### 📦 **Бизнес-сущности** (`src/entities/`)
- User, Product, Order и т.д.
- Содержат типы, API, UI компоненты сущности

## Принципы FSD

1. **Изоляция слоев**: Каждый слой знает только о нижележащих
2. **Вертикальные срезы**: Функционал группируется по бизнес-доменам
3. **Приватность**: Импорты только из нижних слоев
4. **Общность**: Shared слой доступен всем

## Добавление нового функционала

### Добавить новый виджет на главную:
1. Создать папку в `src/widgets/new-widget/`
2. Реализовать компонент `new-widget.tsx`
3. Добавить экспорт в `index.ts`
4. Импортировать в `src/app/page.tsx`

### Добавить новую сущность:
1. Создать папку `src/entities/new-entity/`
2. Определить типы в `types/`
3. Реализовать логику в `lib/`
4. Создать UI компоненты в `ui/`
5. Экспортировать в `index.ts`
